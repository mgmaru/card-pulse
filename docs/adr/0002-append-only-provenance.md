# ADR-0002: 原本と価格観測を追記型で保存する

- 状態: Accepted
- 日付: 2026-09-06

## Context

価格は時間、店舗、状態条件、有効期限によって変わる。parserとカード同定規則も改善される。保存済みの値を上書きすると、当時観測した内容、変更理由、集計結果の根拠を再現できない。

外部情報源は変更・削除・取得不能になる可能性があるため、結果だけでなく解析前の原本と取得メタデータを資産として残す必要がある。

## Decision

- 取得原本と確定した価格観測値を追記型で保存する。
- 観測値からraw artifact、source、shop、ingest run、parser versionへ追跡可能にする。
- 原本にはsource内ID、URL、公開日時候補、取得日時、content hash、media typeを保存する。
- 訂正、失効、再解析は既存行の意味を書き換えず、新しい履歴と関係で表現する。
- 同一原本と同一候補の再投入は、明示的な重複防止規則で冪等にする。
- カード同定が曖昧な候補は確定観測へ混ぜず、原本への参照を持つreview itemとして保存する。

## Consequences

- 集計値から当時の根拠へ戻り、parser変更後も比較・再解析できる。
- 情報源が停止しても保存済みデータを利用できる。
- 保存量が増え、訂正や現在有効な値を得るqueryが単純な更新型より複雑になる。
- 保持期間、backup、機密情報除去を運用として管理する必要がある。

## Alternatives considered

- 最新値だけをupsertする: 容量は小さいが履歴、訂正理由、再現性を失う。
- 正規化結果だけを保存する: parserの誤りを後から検証できず、情報源消失時に再解析できない。

## Validation

固定fixtureの再投入、parser version変更後の再解析、誤同定の訂正をtestし、元の原本と旧結果を参照できることを確認する。保存量は試験運用後に計測し、保持方針を決める。
