# Experiments

このディレクトリには、技術的に取得できたことだけでなく、価格データが判断に役立つかを検証した結果を保存する。

実験文書は `YYYY-MM-DD-<slug>.md` とし、次の項目を含める。

```markdown
# <実験名>

- 期間:
- 対象TCG:
- 対象source:
- 関連ADR:
- 実施者:

## 仮説

## 方法

## 成功条件

## 結果

- 取得試行数:
- 成功率:
- 保存観測数:
- 重複率:
- 未同定率:
- review件数と所要時間:
- parser変更・障害対応時間:

## 判断に役立った事例

## 制約と異常値

## 結論

継続 / 対象変更 / 中止

## 次の判断
```

個別の価格データや取得原本をGitへ貼り付けない。再現に必要なartifact ID、query条件、コードversionを記録し、保存済みデータから確認できるようにする。
