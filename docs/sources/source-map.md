# 情報源マップ

> 状態: MVP対象選定済み（取得許諾待ち）
>
> 最終更新: 2026-09-11

## 目的

MVPで扱う `1 TCG × 2〜3店舗` を、データの有用性、取得可能性、利用条件、カード同定可能性から選ぶ。この文書には比較結果を記録し、各情報源の詳しい根拠は個別source文書へ記載する。

対象TCGをポケモンカードゲームとし、同じカードの買取価格を公開する6情報源を調査した。[ADR-0010](../adr/0010-pokemon-mvp-source-candidates.md)で晴れる屋2、遊々亭、フルコンプ池袋店をMVPの情報源候補とした。各候補について自動取得、保存、fixture、派生集計提供の書面条件を満たすまでCollection Workerを開始しない。

## 選定基準

次を満たす候補を優先する。

1. 同じTCGの同じカードが2店舗以上に存在する。
2. 公開JSON、API、安定したHTMLなど、構造化された形式で取得できる。
3. カード番号または同等の強い識別子を取得できる。
4. 買取価格の意味、状態条件、公開日時または有効期限を判断できる。
5. robots.txt、利用規約、アクセス制限、再利用条件を確認できる。
6. 低頻度の取得で更新を追跡でき、情報源への負荷を抑えられる。
7. 保存とテスト利用が許される代表fixtureを用意できる。

## 取得方式の優先順位

1. 公開APIまたは公開JSON
2. HTML
3. PDF
4. Web画像
5. X公式API
6. Xからの手動取込
7. X非公式取得

形式だけで決定せず、規約、情報の意味、識別精度、fixture保存可否、保守時間を合わせて評価する。

## 初期比較

6情報源はすべてポケモンカードのカード番号と買取価格を公開しており、名前だけに依存しない照合の候補になる。遊々亭、カードラッシュ、晴れる屋2に加え、ドラゴンスターは状態A、トレトクは言語と指定買取条件、フルコンプは店舗別価格を確認できる。

現時点では取得可否が選定上の制約になる。

| 情報源 | 確認済み事実 | 運用上の判断 | 未確認事項 |
| --- | --- | --- | --- |
| 遊々亭 | robots.txtに一般UA向け禁止はなく、規約はコンテンツの無断転載を禁止する | 書面許諾まで自動取得、raw保存、fixture作成を開始しない | 抽出価格の内部保存、自動取得、取得間隔、縮約fixtureの許諾 |
| カードラッシュ | データ利用方針が、正式提携を除く価格情報の自動取得を明示禁止する | 取得間隔にかかわらず実装対象にせず、採用には正式提携を必要とする | 提携時の提供方式、保存期間、fixture、rate limit、再利用条件 |
| 晴れる屋2 | JSONは未認証で取得できる。Web規約はサイト外での複写・利用を禁止する | API hostへの規約適用と利用条件の書面確認まで自動取得、raw保存、fixture作成を開始しない | JSONの公式な位置づけ、自動取得、内部保存、fixture、rate limit、更新周期 |
| ドラゴンスター | `pid`、シリーズ、カード番号、状態A価格を公開する。robots.txtはCloudflare challengeで確認不能 | 権利主体と利用条件の書面確認まで自動取得、raw保存、fixture作成を開始しない | 正式な契約窓口、自動取得、保存、fixture、rate limit、更新周期 |
| トレトク | robots.txtは一般UAに30秒のdelayを指定。規約は商業利用と無断二次利用を禁止する | robots上の取得条件だけでは採用せず、Card Pulseの用途について個別許諾を必要とする | 非商業検証を含む内部保存、fixture、履歴提供、APIまたはfeedの有無 |
| フルコンプ | 店舗別価格表を公開する。池袋店は株式会社イントゥ運営で`www.fullcomp.jp`上の対象を限定できるが、公開されたデータ利用条件は確認できない | 池袋店と対象pathを指定した書面確認まで自動取得、raw保存、fixture作成を開始しない | 自動取得、保存、fixture、rate limit、カード単位ID、記事間schema差 |

robots.txtで明示禁止されていないこと、未認証で取得できること、CORSが許可されていることは、データ利用の許諾とは扱わない。取得間隔は書面許諾または正式提携時の合意事項とする。トレトクを許諾後に取得する場合も、robots.txtの30秒を最小間隔として扱う。

### 同一カードの情報源間比較

`メガレックウザex / M6 ストームエメラルダ / 110/076 / SAR / 日本語`を共通サンプルにした。カード名だけでは各情報源に4候補あったが、セット、番号、レアリティまで揃えると各1候補になった。

| 情報源 | 候補数 | 掲載買取価格 | 原本にある価格条件 | 比較判断 |
| --- | ---: | ---: | --- | --- |
| 遊々亭 | 1 | 25,000円 | 日本語版。カード共通の状態減額規則あり。カード別状態と公開日時なし | 同じ印刷仕様として照合可能 |
| 晴れる屋2 | 1 | 33,000円 | JSONに状態、言語、公開日時、有効期限なし | 属性上は照合できるが、状態条件の等価性は未確認 |
| ドラゴンスター | 1 | 25,000円 | ネット買取限定、状態Aの参考価格。査定時に変動 | 同じ印刷仕様として照合可能 |

3件は同じカードの同時点に近い掲載買取価格として比較候補になる。ただし状態条件と価格保証の意味は一致していないため、一つの同条件価格として統合しない。`price_kind`、状態条件、店舗またはチャネル、取得日時、原本URLを各観測へ保持し、条件差を利用者へ返す。

## 選定結果

- 対象TCG: ポケモンカードゲーム
- MVP選定候補: 晴れる屋2、遊々亭、フルコンプ池袋店
- 取得間隔: 現時点では設定しない。書面許諾で頻度、並行数、条件付きGET、失敗時の停止条件を合意するまで自動取得しない
- 共通して取得できるカード識別項目: カード名、セット、カード番号。レアリティ、言語、版・加工・封入状態を補助し、欠損または衝突はreviewへ送る
- 比較に使用する価格条件: 日本円の掲載買取価格。状態、価格保証、店舗またはチャネル、取得日時を別々に保持し、等価性を確認できない条件は統合しない
- 保留した有力候補と理由: ドラゴンスターはカード識別項目が有力だが、Cloudflare challengeと許諾主体を独立して技術検証する必要があるため、`CP-0070`後に`CP-0071`で再検討する
- 見送った有力候補と理由: カードラッシュは提携なしの自動取得禁止、トレトクは商業利用・二次利用制限がある
- 取得開始条件: `CP-0070`で3候補の書面条件と比較可能性を検証し、必要条件を満たす2〜3店舗を`CP-0072`でMVP採用として確定する
- 選定ADR: [ADR-0010](../adr/0010-pokemon-mvp-source-candidates.md)
