## 目的

MVPで扱う `1 TCG × 2〜3店舗` を、データの有用性、取得可能性、利用条件、カード同定可能性から選ぶ。この文書には比較結果を記録し、各情報源の詳しい根拠は個別source文書へ記載する。

候補はまだ登録されていない。調査時は [source文書テンプレート](template.md) を複製し、確認日と根拠URLを伴う事実だけを記載する。

## 選定基準

次を満たす候補を優先する。

1. 同じTCGの同じカードが2店舗以上に存在する。
2. 公開JSON、API、安定したHTMLなど、構造化された形式で取得できる。
3. カード番号または同等の強い識別子を取得できる。
4. 買取価格の意味、状態条件、公開日時または有効期限を判断できる。
5. robots.txt、利用規約、アクセス制限、再利用条件を確認できる。
6. 低頻度の取得で更新を追跡でき、情報源への負荷を抑えられる。
7. 保存とテスト利用が許される代表fixtureを用意できる。

## 取得方式の優先順位

1. 公開APIまたは公開JSON
2. HTML
3. PDF
4. Web画像
5. X公式API
6. Xからの手動取込
7. X非公式取得

形式だけで決定せず、規約、情報の意味、識別精度、fixture保存可否、保守時間を合わせて評価する。
